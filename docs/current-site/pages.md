# 現行サイトのページ一覧

調査対象：https://waku-8.com/ （調査方法は [README.md](README.md)）。機械的な一覧は [pages.json](pages.json)。

## ナビゲーション

### ヘッダー（PC幅の画面上の並び順）

1. わくや概要（`/summary/`）
2. わくやの想い（`/thought/`）
4. 出張わくや（`/deliver/`）
5. ブログ（`/blogs/`）
6. お問い合わせ（`/contact/`）

（ナビにはこのほかカラーミーショップ「オンラインショップ」https://waku-8.shop-pro.jp/ がある）

### フッター

1. わくや概要（`/summary/`）
2. プライバシーポリシー（カラーミーショップ https://waku-8.shop-pro.jp/?mode=privacy ）
3. 特別商取引法（カラーミーショップ https://waku-8.shop-pro.jp/?mode=sk#info 。表記は現行のまま「特別商取引法」）
4. 送料について（カラーミーショップ https://waku-8.shop-pro.jp/?mode=sk ）

フッターにはこのほか SNS（X・Facebook・Instagram）のアイコンリンクと「©2023 wakuya.」がある。住所・電話番号などの店舗情報はフッターにない。
