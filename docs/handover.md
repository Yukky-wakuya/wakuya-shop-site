# 現行サイトの管理会社からの引き継ぎ

現行のウェブサイト・ドメイン・メール・オンラインショップは、管理会社が管理しています。
これを有限会社和久屋（以下、店）が引き継ぎ、制作に関わる人が運用できるようにします。

## 1. 方針（2026-11-24 決定）

| 対象 | 方針 | 詳しい手順 |
|------|------|------------|
| ウェブサイト | このリポジトリのサイト（Cloudflare Pages）を使う。現行の WordPress は使わない | [deploy.md](deploy.md) |
| ドメイン・メール | 管理会社から引き継ぐ。構成は、できるかぎり Cloudflare にまとめる（DNS・登録・メールの転送） | [domain.md](domain.md) |
| オンラインショップ | 今のカラーミーショップのアカウント（`waku-8.shop-pro.jp`）を引き継ぐ。カード決済（GMO イプシロン）の契約があるため、アカウントは作り直さない。デザインは著作権に配慮して、こちらで作ったものに替える | §4 |
| 表記 | 基本は「わくや」。フッターの長い名前だけ「わくや \| 福島県民芸雑貨 \| 有限会社和久屋」 | `src/components/Footer.astro` |

## 2. 管理会社から受け取るもの

管理会社への依頼のメールは、この一覧のとおりにお願いする。

### ドメイン（waku-8.com）

- [ ] 登録先（ムームードメインと思われる）と、契約者・登録者の名義
- [ ] 有効期限（2027-10-05 と思われる）と、移管が済むまでの更新のお願い
- [ ] DNS レコードの一覧（管理画面の写しでよい）
- [ ] 移管の準備：Whois 代理公開をやめる、ロックを外す、AuthCode を発行する（[domain.md](domain.md) §5）
- [ ] ネームサーバーの変更（こちらで Cloudflare のネームサーバーを伝える。ログインをもらえるならこちらで行う）
- [ ] 移管の承認メールが届いたら承認する

### メール

- [ ] 使っているメールアドレスの一覧（`shop@waku-8.com` のほかにあるか）と、転送の設定
- [ ] メールボックスに入るための設定（受信サーバー・ユーザー名・パスワード）。中身を保存するため
- [ ] メールの切り替えが済むまで、ロリポップを解約しないこと

### ウェブサイト

- [ ] WordPress のバックアップ（ファイルとデータベース）
- [ ] 現行サイトの文章・写真・ロゴ・デザインのうち、管理会社が著作権を持つものと、引き続き使ってよいもの
- [ ] ロリポップの契約の解約の時期と、費用の精算

### カラーミーショップ

- [ ] 契約者の名義（店か、管理会社か）
- [ ] 管理画面のログイン ID・パスワード・登録メールアドレス・2段階認証の端末
- [ ] カラーミーショップの利用料の支払い者と支払い方法
- [ ] GMO イプシロンの契約者の名義・管理画面のログイン・入金先の口座
- [ ] ショップにつないでいるほかのサービス（Instagram・広告・外部アプリなど）
- [ ] 今のデザイン（テンプレート）の著作権の持ち主。デザインを替えるまでの間、今のまま使ってよいか

## 3. 進める順番

1. 管理会社に依頼のメールを送り、§2 を受け取る
2. カラーミーショップのログインを受け取ったら、すぐにパスワード・登録メールアドレス・2段階認証を店のものに変える（§4）
3. DNS を Cloudflare に移す（[domain.md](domain.md) §3 の A・B）
4. ウェブを新しいサイトに切り替える（[domain.md](domain.md) §3 の C、[deploy.md](deploy.md) §3）。あわせてショップへのリンク先を `waku-8.shop-pro.jp` に変える（§4）
5. メールを Cloudflare Email Routing に移す（[domain.md](domain.md) §4）
6. ドメインを Cloudflare Registrar に移管する（[domain.md](domain.md) §5）
7. 管理会社にロリポップとムームードメインの解約を依頼する（[domain.md](domain.md) §6）

## 4. カラーミーショップ

### 受け取った直後

- 管理画面のパスワードを変え、登録メールアドレスを `shop@waku-8.com`（または店の Gmail）に、2段階認証を店の端末にする
- 管理会社のスタッフのアカウントがあれば、消す
- 契約者の名義が管理会社のときは、カラーミーショップのサポートに名義変更の方法を問い合わせる。**GMO イプシロンの契約は、名義が店でなければ作り直しが要る**ことがあるので、イプシロンにもあわせて確かめる

### デザイン

- 今の `colorme/template/` は、公開中のショップのデザイン（HTML の構造と CSS）をもとにしている（[colorme/README.md](../colorme/README.md)）。**この CSS は管理会社の制作物の可能性があるため、販売中のショップには反映しない。**
- 販売中のショップに出すテンプレートは、カラーミーショップの公式テンプレートをもとに、ホームページの 007 の仮のデザインに合わせて、こちらで作り直す。作り直しは、別の機能として spec を立てて進める
- 作り直しが済むまでは、今のデザインのまま運用する（管理会社の了承を受ける。§2）

### ホームページとのリンク

今のホームページは、プロジェクト用のショップ（`wakuya.shop-pro.jp`）にリンクしています。販売中のショップを引き継ぐので、ウェブの切り替え（§3 の 4）のときに次を変えます。

- `src/data/site.ts` の `shopUrl` と、`footerNav` のショップ内のページ
- `src/data/recommended.ts` のおすすめ商品のリンク。商品 ID は、[colorme/product-map.json](../colorme/product-map.json) で新しい ID から元の ID に戻す
- `tests/links/links.spec.ts`・`tests/top/top.spec.ts`・`scripts/check-shop-links.ts` の `SHOP`
- ショップのテンプレートの `site_url`（ホームページの URL）を `https://waku-8.com` にする（[colorme/README.md](../colorme/README.md)）

プロジェクト用のショップは、テンプレートを試す場所として残します。
