# Data Model: トップページとブログ

## 1. 記事（Post）

保存先：`src/content/blog/<番号>/index.md`（写真は同じディレクトリ）。スキーマは `src/content.config.ts`。

| 項目 | 型 | 必須 | 内容 |
|------|----|------|------|
| `id` | 文字列（`^\d+$`） | ○ | ディレクトリ名。URL `/<id>/` になる。重複はファイルシステム上で起きない |
| `title` | 文字列（1文字以上） | ○ | 記事のタイトル（h1） |
| `date` | 日時（`2026-04-24T14:25:06+09:00`） | ○ | 公開日時。日本時間で書く |
| `categories` | カテゴリの slug の配列（1つ以上） | ○ | §2 の slug 以外はビルド失敗 |
| `hero` | 画像（相対パス） | — | アイキャッチ画像。ないときは代わりの画像（§4） |
| `heroAlt` | 文字列 | `hero` があるとき○ | 記事ページの見出し部分での代替テキスト |
| `description` | 文字列 | — | なければ本文の先頭120文字から作る（research.md §11） |
| `draft` | 真偽 | — | `true` なら公開しない |
| 本文 | Markdown | ○ | 写真は `![代替テキスト](./写真.jpg)` |

**公開の判定**：`draft` が `true` でなく、`date` がビルドした時点より前のもの。

**並び順**：`date` の新しい順、同じなら `id` の数値の大きい順。

**前後の記事**：上の並び順で、1つ新しい記事を「次の記事」、1つ古い記事を「前の記事」とする。

## 2. カテゴリ（Category）

保存先：`src/data/categories.ts`（1か所で管理。FR-017）

| slug | 表示名 | 並び順（サイドバー） |
|------|--------|----------------------|
| `news` | お知らせ | 1 |
| `folk_craft` | 民芸品について | 2 |
| `column` | 店主のコラム | 3 |
| `exhibit` | 出展について | 4 |
| `etc` | その他 | 5 |

並び順は現行のサイドバーと同じ。記事が0件のカテゴリは、一覧ページもリンクも出さない。

## 3. おすすめ商品（RecommendedProduct）

保存先：`src/data/recommended.ts`、画像は `src/assets/recommend/`

| 項目 | 型 | 内容 |
|------|----|------|
| `name` | 文字列 | 商品名（画面に表示） |
| `image` | 画像（import） | 商品の写真 |
| `alt` | 文字列 | 代替テキスト。商品名と同じでよいときは空にせず商品名を書く |
| `url` | `https://waku-8.shop-pro.jp/?pid=…` | カラーミーショップの商品ページ |

配列の順に表示する。件数は4件を基本とし、4件以外でも崩れない（FR-004）。

## 4. 代わりの画像

アイキャッチ画像のない記事のサムネイルと見出し部分には、現行と同じ代わりの画像（灰色の地にロゴ、
`src/assets/brand/no-image.png`）を使う。代替テキストは空（一覧）または「わくやのロゴ」（記事ページ）。

## 5. 一覧のページ（ListPage）

ビルド時に計算する（保存しない）。

| 項目 | 内容 |
|------|------|
| `posts` | そのページに出す記事（最大12件） |
| `current` | ページ番号（1から） |
| `last` | 最後のページ番号 |
| `url(n)` | n=1 なら `/blogs/`（カテゴリは `/category/<slug>/`）、2以上は `…/page/<n>/` |

## 6. サイトの設定（SiteConfig）

`site.config.ts` の `resolveSiteConfig(env)` が返す。詳細は [contracts/site-config.md](contracts/site-config.md)。

| 項目 | 内容 |
|------|------|
| `url` | 公開するURL（末尾の `/` なし） |
| `env` | `test` か `production` |
| `indexable` | `env === 'production'` |

## 7. URL の対応（UrlMapping）

`docs/current-site/url-mapping.md` の行。002 で更新するのは、トップ・記事29件・ブログ一覧3ページ・
カテゴリ一覧7ページの40行。`新URL` は同じパス、`対応方法` は「同じURL」。
