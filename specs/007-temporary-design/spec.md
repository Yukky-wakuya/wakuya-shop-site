# 007 仮のデザインへの差し替え

- 作成日：2026-11-08
- 状態：実装済み（仮のデザイン）

## 背景

これまでのデザイン（現行サイト https://waku-8.com/ を踏襲したもの）が、今後使えなくなる可能性がある。
使えるかどうかが決まるまでの間、ホームページの全ページを別のデザインに差し替える。
元のデザインは、使えることになったら戻せるように残す（[docs/design-original.md](../../docs/design-original.md)）。

ページ構成・URL・文章・写真・リンク・構造化データは変えない。変えるのは見た目だけ。

## デザインの方針（店からの依頼）

- 福島の民芸、旅館の、なつかしさを感じさせる
- 同時に、現代美術館のようなすっきりしたページにする
- 写真を切り抜く形やふきだしなど、目にうるさくない程度に、あかべこ・こけし・三春駒など福島の民芸を感じさせるものを随所に入れる

## 現行の状態・変更内容・変更理由（開発原則I）

開発原則I（既存サイトの踏襲）の例外として、デザインの印象を変える。変更理由は「元のデザインが使えなくなる可能性があるため」。

| 部分 | 現行の状態（元のデザイン） | 変更内容（仮のデザイン） |
|------|---------------------------|--------------------------|
| 色 | 白地、朱 #a61f29、フッターは青緑 #3e5256 | 和紙色の地 #f7f3ea、墨 #24211d、赤べこの朱 #a8322b、藍 #1f2d3d |
| ロゴ | ロゴの画像（header_logo.svg など） | こけしの図と明朝の文字「民芸くらふと わくや」 |
| ナビ | 縦書きの横並び（768px 以上） | 明朝の横並び（1025px 以上）。それより狭い幅は開閉メニュー |
| 見出し | 模様のアイコン＋見出し | 小さな英字の添え書き＋明朝の見出し＋細い罫線（美術館の展示表示のように） |
| 写真の切り抜き | 曲線（なみ形）の切り抜き | 旅館の花頭窓・アーチ窓・こけし・起き上がり小法師・丸の形 |
| 模様 | 朱・灰色・緑などの模様の画像 | あかべこ・こけし・三春駒・起き上がり小法師の小さな図（src/components/Mingei.astro）と、ふきだし（src/components/Fukidashi.astro） |
| オンラインショップの帯 | 朱の帯と白抜きのロゴ | 藍ののれん（切れ目と、あかべこの白い丸の紋） |
| フッター | 写真の帯とアーチ | 棚に並んだ民芸の図と、藍の面 |
| ファビコン・OGP 画像・写真のない記事の画像 | ロゴの画像 | あかべこの図（scripts/temporary-design/make-images.ts で作る） |

ふきだしの文言（新しく足した短い言葉）：

- トップ：「ようこそ、わくやへ。」
- わくや概要：「昭和五十年、卯年の生まれです。」
- 出張わくや：「荷台にぎゅっと詰めて、でかけます。」
- お問い合わせ：「民芸品のこと、出張のご依頼も、お気軽にどうぞ。」
- 404：「道に迷ってしまったようです。」

## カラーミーショップ（wakuya.shop-pro.jp）

ショップのテンプレートも同じ方針で差し替え、2026-11-08 に反映した（テンプレートは1つで、push するとすぐ公開される）。
HTML の仕組み（独自タグ・カート・スクリプト）は変えず、CSS を上から重ねている（colorme/README.md）。

| 部分 | 元のデザイン | 仮のデザイン |
|------|-------------|-------------|
| ロゴ | 管理画面のロゴ画像 | こけしの図と明朝の文字 |
| 地の色・書体 | 白、Noto Serif JP | 和紙色、游明朝 |
| 見出し | 明朝の見出し | 英字の添え書き＋見出し＋朱の短い線 |
| 紹介の写真 | 四角 | 花頭窓の形 |
| わくやの想いの写真 | 四角 | 上の丸いアーチ窓 |
| 商品の写真 | 灰色の地 | 額装の台紙（白い余白と細い線） |
| カートに入れるボタン | 緑 | 藍の丸いボタン |
| フッター | 生成り | 棚に並んだ民芸の図と、藍の面 |

カートの画面の色は管理画面でしか変えられないため、緑のまま（colorme/README.md に変える値を書いた）。

## 使い続けているもの

- 店の写真（各ページの見出しの写真、わくやの想いの写真3枚、沿革の絵、出張の写真、商品の写真）。
  わくやの想いの写真3枚と沿革の絵は、元のデザインで曲線に切り抜かれた画像のため、拡大して中央を使っている
- SNS のアイコン（X・Facebook・Instagram の各サービスのマーク）

元のデザインの画像（src/assets/brand/ のロゴ・模様など）は、戻すときのために消さずに置いている（どこからも使っていない）。
