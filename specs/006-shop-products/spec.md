# Feature Specification: 商品の移行とホームページ・ショップの相互リンク

**Feature Branch**: `006-shop-products`

**Created**: 2026-11-05

**Status**: 商品情報の登録と相互リンクまで完了。画像、オプション、在庫は未完了（下記）

**Input**: User description: "既存のショップにある商品を今回作ったショップに入れる。今回作った通販サイトとホームページを相互に行き来できるようにする"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 商品を新しいショップで見られる (Priority: P1)

販売中のショップ（`waku-8.shop-pro.jp`）の商品が、プロジェクト用のショップ（`wakuya.shop-pro.jp`）に同じカテゴリー、グループ、税込価格、説明文で出る。

**Independent Test**: 商品数と税込価格が一致する。

### User Story 2 - ホームページとショップを行き来できる (Priority: P1)

ホームページのショップへのリンクが `wakuya.shop-pro.jp` へ、ショップの公式サイトへのリンクがホームページへ移動する。

**Independent Test**: 両方のリンク先を確かめる。

## Requirements *(mandatory)*

- **FR-001**: 販売中のショップを変更してはならない
- **FR-002**: 旧商品 ID と新商品 ID の対応を `colorme/product-map.json` に残す
- **FR-003**: ホームページの URL は、ショップのテンプレートの1か所で変えられるようにする
- **FR-004**: ショップの URL が変わったときに検査できるよう、リンクの確認ツールを新しいショップに合わせる

## 移行の結果（2026-11-05）

- 商品 65 件、カテゴリー 9 件、グループ 7 件を登録し、全件の税込価格が一致した。おすすめ 20 件、人気 4 件をトップと同じ順に設定した。
- 公開ページから読み取ったため、原価、メモ、非公開の商品は移していない。

## 未完了

- **オプション（14 件）**：API では新規に作成できない。管理画面または CSV で登録する。
- **在庫数**：公開ページに出ないため読み取れず、在庫を管理しない設定で登録した。注文を受ける前に実数を入れる。
- 記事 `/113/` の販売終了の商品へのリンク（`?pid=179065997`）は、対応する商品がないためショップのトップへ向けた。
