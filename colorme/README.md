# カラーミーショップのテンプレート

`template/` は、公開中のショップ（`waku-8.shop-pro.jp`）の見た目を再現したテンプレートです。プロジェクト用のショップ（`wakuya.shop-pro.jp`）で動作を確かめています。

- 方針と経緯：[specs/005-colorme-shop/spec.md](../specs/005-colorme-shop/spec.md)
- 外から見えない画面の案：[specs/005-colorme-shop/mockups/index.html](../specs/005-colorme-shop/mockups/index.html)

## 作り方

- HTML：公開ページの構造に、公式テンプレート DISCOVER と同じ独自タグを当てはめました。カートのフォームは DISCOVER のタグのままです。
- CSS：公開中のショップの CSS を UTF-8 にしたものです。追加は `product.css` の末尾の「売り切れ」だけです。
- `.on('ready')` と `.size()` は jQuery 3 で動かないため書き換え、スライドの部品は jQuery 3.7 対応版に替えました。この書き方は古い jQuery でも動く想定ですが、公開中のショップ（jQuery 1.11）では試していません。

## 更新のしかた

`colorme` の CLI を使います（導入は[公式の手順](https://developer.shop-pro.jp/getting-started/cli)）。Windows の PowerShell では `colorme.cmd` と打ちます。

```text
colorme template push --path colorme/template
colorme template preview --path colorme/template
```

`push` は、対象のテンプレートにすぐ反映されます。**公開中のショップに対して実行するときは、先に今のテンプレートを `colorme template pull` で控えてください。**

## ホームページとのリンク

公式サイトへのリンクは `template/index.html` の先頭の `site_url` で決めています。ドメインが決まったら、この値だけを変えます。ホームページ側のショップの URL は `src/data/site.ts` です。

商品の旧 ID と新 ID の対応は [product-map.json](product-map.json) です。

## 管理画面で設定するもの

テンプレートでは変えられない項目です。

### カートの色（案1）

「デザイン」→ テンプレート編集 →「ショッピングカートの項目編集」。プレビューがないため、設定後に実際のカートで確かめます。

| 項目 | 値 |
|------|----|
| メインボタンの背景色 | `#357029` |
| メインボタンの文字色 | `#ffffff` |
| 操作できるパーツのキーカラー | `#2b5c21` |
| アクセントカラー（会員系の表示部分） | `#357029` |
| アクセントカラー（購入ステップ・必須項目の表示部分） | `#357029` |

文字サイズ、完了やエラーの色などは変更できません。

### `about` ページ（フリーページ）

テンプレートには含まれません。会社情報の表から「営業時間」「定休日」の行を削除し、メールアドレスを `shop@waku-8.com` にします。

### プロジェクト用のショップに登録するもの

公開中のショップと同じ見た目にするために必要です。

- ロゴ画像、スライドショーの写真、商品、カテゴリー、グループ
- SNS の URL、著作権の表記（公開中は「2023 wakuya」）
- 配送方法、支払い方法、特定商取引法の表記

## 公開中のショップに依存している値

ショップを移すときは、次を差し替えます。

| 場所 | 内容 |
|------|------|
| `template/top.css` | 画像4枚（`img21.shop-pro.jp/PA01503/720/…`）。公開中のショップのアカウントの画像なので、そちらを解約すると表示されなくなる |
| `template/index.html` の左の列 | バナー画像と、リンク先のグループ ID・商品 ID |

## 確かめたこと（2026-11-05、`wakuya.shop-pro.jp`）

- トップ、商品、売り切れの商品、カテゴリー、検索（0件）、ショッピングガイド、プライバシーポリシーが表示され、スクリプトのエラーがない
- PC とスマートフォン幅（390px）で横のはみ出しがない。スマートフォンのメニューが開く
- 商品をカートに入れられ、カートの画面に商品が出る。売り切れの商品はボタンを押せない

### まだ確かめていないこと

- 商品画像がある商品のページ、写真の拡大（テスト商品に画像を登録できなかった）
- 注文を確定するまでの流れ
- オプションのある商品、商品グループ、複数ページの一覧、ログイン後の表示
- 公開中のショップでの動作
