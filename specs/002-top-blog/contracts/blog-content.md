# Contract: 記事ファイルの形式

更新担当者が新しい記事を書くときの形式（FR-013〜FR-015）。手順書は `docs/updating.md`。

## 置き場所

```text
src/content/blog/
└── 258/                 # 記事の番号 = URL（/258/）。既存の番号と重ならない数字
    ├── index.md         # 記事
    ├── hero.jpg         # アイキャッチ画像（任意）
    └── photo-1.jpg      # 本文の写真（任意）
```

新しい番号は、既存の最大の番号より大きい数字にする（`npm run blog:next-id` で表示）。

## index.md

```markdown
---
title: 初陣！
date: 2026-04-24T14:25:06+09:00
categories: [news]
hero: ./hero.jpg
heroAlt: まんじゅう祭りの出店ブースで、民芸品の棚を見る子ども
description: （任意）検索結果に出る説明。書かなければ本文の先頭から作る
---

本文。段落は空行で区切る。

![ブースに並べた張り子の干支看板](./photo-1.jpg)

[オンラインショップの商品ページ](https://waku-8.shop-pro.jp/?pid=190271475)
```

- `categories` は `news`・`folk_craft`・`column`・`exhibit`・`etc` から1つ以上（data-model.md §2）。
- 未来の `date` の記事は、その日時より後にビルドされるまで公開されない。
- 本文の見出しは `##` から使う（`#` は記事タイトルが使う）。

## ビルドが失敗する場合（FR-014）

| 原因 | エラーに出るもの |
|------|------------------|
| `title`・`date`・`categories` がない、空 | ファイルのパスと項目名 |
| 存在しないカテゴリ | ファイルのパスと、使えるカテゴリの一覧 |
| `hero` や本文の画像のファイルがない | ファイルのパスと画像のパス |
| `hero` があり `heroAlt` がない | ファイルのパスと項目名 |
| ディレクトリ名が数字でない | ディレクトリ名 |
