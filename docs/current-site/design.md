| 用途 | 現行の指定 | 使用 | 新サイト |

- 現行サイトは Webフォントを使っておらず、OS に入っている游ゴシック・游明朝・ヒラギノで表示している。
  新サイトも同じ方針とし、**Webフォントは使わない**（T024：Fontsource は導入しない）。
  表示が速く、現行と同じ見え方になる。Windows・Mac・iPhone では現行と同じ書体になる。
- 太さは 400（標準）がほとんどで、700 はブログ本文の強調のみ。
- 字間は全体に `0.1em`（16px で 1.6px）。

## 行間・余白

- 行間：本文 `1.5em`（24px）。段落 28px（1.75）。→ `--line-height-base: 1.5`
- 本文エリア：幅 90%、最大 1000px（`.content_inner`）。
- 余白の主な値：5px（SNS・フッターナビの間隔）、10px、15px、20px、30px（見出し下）、50px（ショップの帯の内側）、
  60px／120px（ショップの帯の下、SP／PC）、80px（アーチ）。→ `--space-2xs`〜`--space-2xl`
- 一覧（おすすめ商品・お知らせ）の間隔：縦 35px・横 70px。

## 角丸・影

- 角丸：フッター上端とお知らせの帯のアーチ（`50% 80px`）、出張わくやのボタン（`9999px`）。
- 影：使っていない。

## ブレークポイント

- `max-width: 767px`（スマートフォン）／`min-width: 768px`（タブレット以上）／`min-width: 1025px`（広いPC）。

## 共通レイアウトの構成

### ヘッダー

- PC（768px 以上）：左にロゴ（幅194px）。右に**縦書き・明朝・20px** のナビ。その下に SNS アイコン（27px）。
- ナビは縦書きを右から左へ読む順：**わくや概要 → わくやの想い → オンラインショップ → 出張わくや → ブログ → お問い合わせ**。
  HTML の記述順はこの逆（`お問い合わせ` が先）。
- スマートフォン（767px 以下）：左にロゴ（幅97px）、右上に固定のハンバーガー（3本線 `#555`）。
  開くと右から生成り色のパネルが出て、白抜きロゴと同じ順のナビ（中央寄せ・下線区切り）。jQuery で開閉。

### フッター

- 店先の写真（`footer_bg.jpg`、薄いモノクロ）の帯に中央のロゴ → 青鈍色のアーチ → SNS アイコン（白）→
  フッターナビ（わくや概要・プライバシーポリシー・特別商取引法・送料について）→ ©2023 wakuya.
- フッターの前に、臙脂色の「オンラインショップ」の帯（全ページ共通）。画面右下に「上へ戻る」の固定ボタン。

## 現行から変える点

開発原則I・IV により、現行サイトから変える点を「現行・変更・理由」で記録する。
**spec.md の「現行サイトからの変更」にも同じ内容を書く**（analyze の指摘 C1）。

| # | 現行 | 変更 | 理由 |
|---|------|------|------|
| 1 | スマホメニューは jQuery で開閉するハンバーガー | `<details>` で開閉するボタン（3本線＋「メニュー」の文字）。パネルはヘッダーの下に開く | JavaScript なしで全項目にたどり着けるようにする（FR-012・原則V）。ボタンの意味を文字で示す（原則IV） |
| 2 | フッターに店舗情報がない | 店名・住所・電話番号・営業時間をフッターに表示 | 構造化データ（LocalBusiness）の内容を画面にも表示するため（原則VIII）。表記をそろえ、AI・検索エンジンに同じ店と認識させる |
| 3 | フッターの法定表記のリンクが「特別商取引法」 | 「特定商取引法に基づく表記」 | 法律の正式名称に合わせる（情報が不正確） |
| 4 | 外部リンクに新しいタブで開くことの説明がない | 視覚的に隠した「（外部サイト・新しいタブで開きます）」を付ける | スクリーンリーダーの利用者に伝えるため（原則IV） |
| 5 | フォーカスの表示がない | 臙脂色の枠を表示 | キーボード操作で位置が分かるようにする（原則IV） |
| 6 | 「上へ戻る」の固定ボタン（JavaScript） | 001 では作らない | JavaScript が必要なため。必要ならページ内リンクで後の機能で作る |
| 7 | ショップの帯の文字 46px（1025px 以上） | 40px に統一 | 1025px 以上だけの差が小さく、トークンを増やさないため |
| 8 | SNS アイコン 27px（タップ領域も 27px） | 見た目は 27px のまま、タップ領域を 44px に広げる | 押しやすさ（WCAG 2.2 AA 2.5.8） |
| 9 | ヘッダーの h1 がロゴ画像（全ページ同じ）、meta description が全ページ同じ、canonical・構造化データなし | ロゴは h1 にせず、各ページに固有の h1・description・canonical・構造化データを付ける | 原則VIII |

## 参考：現行サイトの SEO 上の状態

- title は全ページ「わくや | 福島県民芸雑貨 | 有限会社和久屋 » ページ名」。meta description は全ページ同じ文章。
- `<h1>` はヘッダーのロゴ画像で、本文の見出しは h2 から始まる。
- `meta keywords` に「キーワード」という仮の文字が入っている。
