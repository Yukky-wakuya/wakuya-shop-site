# Feature Specification: カラーミーショップのテンプレートの控えと調整

**Feature Branch**: `005-colorme-shop`

**Created**: 2026-11-05

**Status**: Draft（所有者の操作待ち。下の「次に必要な操作」を参照）

**Input**: User description: "今のショップの画面を再現する。デザイン会社からテンプレートをもらえなかったため作り直す。見つかった点は基本的に現状維持。外から見えない画面はおすすめのデザインで作る"

## 決めたこと（2026-11-05、所有者）

- 公開ページは、今の画面をそのまま再現する。
- カートなどの主要な操作の色は、案1の緑 `#357029`（画面例：[mockups/index.html](mockups/index.html)）。
- 支払い方法の表記の不一致、特定商取引法の住所、送料の案内、幅 360px のはみ出し、重複するバナーなどは、いったん現状維持。
- `about` ページ（`?mode=f1`）は例外として直す：営業時間と定休日を外し、メールアドレスを `shop@waku-8.com` に揃える。

## 調べて分かったこと

- 公式の CLI（`@colorme/cli`、2026年4月公開）で、テンプレートの HTML・CSS をダウンロード、アップロード、プレビューできる（[手順](https://developer.shop-pro.jp/getting-started/cli)）。今のテンプレートを取り出せれば、作り直しは不要になる。
- `colorme template push` が公開中の画面にすぐ反映されるかは、公式の手順に書かれていない。確かめるまでは、公開中のテンプレートへ push しない。
- カート画面は HTML を編集できず、色の設定が中心。文字サイズ、完了やエラーの色などは変更できない（公式ヘルプの検索結果の要約による。管理画面で最終確認する）。
- 店舗の管理画面のデザインは、GMO ペパボの提供する画面のため変更できない見込み。
- 独自タグの公式の一覧は自動では読めなかった。カートのフォームや在庫切れのタグを推測で書くと販売を止めるおそれがあるため、推測では書かない。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 今のデザインを失わない (Priority: P1)

所有者が、今のテンプレートの控えをリポジトリに持ち、問題が起きたら元に戻せる。

**Independent Test**: 控えのファイルが取得でき、差分で変更点を確かめられる。

### User Story 2 - 買い物の途中で印象が変わらない (Priority: P2)

お客様が商品ページからカート、購入手続きへ進むとき、操作の色が同じ緑で続く。

**Independent Test**: カートの色の設定後に、実際の画面で商品ページとカートの色を見比べる。

### User Story 3 - 古い店舗情報が残らない (Priority: P2)

`about` ページに営業時間と定休日がなく、メールアドレスが公式サイトと同じである。

**Independent Test**: 反映後に `?mode=f1` の表示を確かめる。

## Requirements *(mandatory)*

- **FR-001**: 変更の前に、今のテンプレートの控えを取らなければならない
- **FR-002**: 公開ページの見た目と購入の動きを変えてはならない（FR-004 を除く）
- **FR-003**: 公開中のテンプレートへの反映は、所有者の確認を得てから行わなければならない
- **FR-004**: `about` ページの店舗情報を、「決めたこと」のとおりに直す
- **FR-005**: カートの色は案1とし、元の色の控えを残す

## 次に必要な操作（所有者）

1. カラーミーショップ デベロッパーで OAuth アプリを作り、CLI でログインする
2. `colorme template list` と `colorme template pull` で今のテンプレートを取り出す

取り出せないときは、公開ページの HTML と CSS をもとに作り直す。その場合も、独自タグは公式の一覧で確かめてから書く。
